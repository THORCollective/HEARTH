## Why

This hunt helps uncover misconfigurations and potential abuse by adversaries when it comes to service account logons. Identifying users doing this in an organization can help close a potential threat surface from existing for a future adversary.

## Implementation Notes

This assumes you have a baseline of expected behavior for service accounts in the environment. Several forms of telemetry exist but you must be able to first associate a login to a service account. Attribution helps identify how the initial login was started. The best type of telemetry would be EDR based analytics such as Defender for Endpoint - DeviceProcessEvents, DeviceLogonEvents. An alternative would be Windows Event logging via 4624 where Logon Type is 10 or 2. You will need to be able to capture the Logon Type, and the logon which is authenticating as the Service Account.
