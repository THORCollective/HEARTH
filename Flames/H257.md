# H257

`scp.exe -o ProxyCommand="powershell -ep bypass -file .\$Recycle.Bin\setup.ps1" . localhost:.`

There is no SSH server. The transfer fails. That does not matter, because `ProxyCommand` is evaluated and spawned *before* the connection is attempted — so PowerShell runs, the script executes, and the failure that follows is cosmetic. The destination `. localhost:.` is a placeholder that exists only to make the command line syntactically valid.

Two things make this worth a hunt. The parent process in every downstream telemetry record is a Microsoft-signed binary in System32, and the payload is parked in `C:\$Recycle.Bin` — a hidden system folder that most analysts have never opened and a lot of tooling skips by default. HEARTH had no coverage of the OpenSSH proxy-execution family.

## Why

- **OpenSSH is in-box on Windows, so this is available everywhere with nothing to install.** `scp.exe` and `ssh.exe` have shipped by default since Windows 10 1809. Application-control policies that allowlist Microsoft-signed System32 binaries permit this by construction, and the technique needs no dropped tooling to work.
- **It breaks parent-child heuristics rather than evading them.** A great deal of detection logic keys on "Office spawned PowerShell" or "browser spawned a script host." `scp.exe` spawning PowerShell fits none of those patterns and reads as legitimate administrative SSH use at a glance.
- **`$Recycle.Bin` as a payload directory is under-hunted.** It is hidden, it is system-owned, users are conditioned to think of it as empty, and analysts rarely enumerate it. A `.ps1` executing from there is anomalous with essentially no benign counterpart — which makes it a useful standalone query even independent of the scp vector.
- **The lineage query survives obfuscation of the command line.** Attackers can encode or restructure the `-o` value, but they cannot avoid `ssh.exe` being the parent of whatever runs. Hunting the process relationship rather than the string is what keeps this from being defeated by a slightly different quoting style.
