# H271

Threat actors are registering malicious Microsoft Edge native messaging host manifests via `HKCU\SOFTWARE\Microsoft\Edge\NativeMessagingHosts` registry sub-keys to bridge a sideloaded browser extension with a Python-based host process, enabling arbitrary command execution beyond the browser sandbox on compromised endpoints.

## Why
- Native messaging host registration is a rarely-monitored registry artifact that allows a sandboxed browser extension to escape its confinement and execute arbitrary shell/PowerShell commands, file writes, and process enumeration on the host OS — a significant and often-missed privilege escalation path.
- This behavior was central to the Edgecution backdoor observed in UNC6692 intrusions, directly enabling credential/session monitoring on banking, email, VPN, and administrative portals and providing hands-on-keyboard access for a ransomware initial access broker (linked to Payouts King).
- Detecting the creation of new `NativeMessagingHosts` registry keys, unusual `com.<random>.api.json` manifest files, and the accompanying `HKCU\SOFTWARE\Microsoft\Edge\AppKey` value can catch this technique early — before the C2 WebSocket channel is established and before ransomware deployment or credential exfiltration occurs.
