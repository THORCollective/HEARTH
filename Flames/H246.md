# H246

Rapid7's exposed-lab teardown (2026-07-20) recovered 89 encrypted droppers from the operator's staging server and documented the storage trick behind them: the real module is AES-encrypted and GZip-compressed, then **written into the IDAT chunks of a PNG** and saved under a database extension (`loader-pool.db`). At runtime it is read back, decrypted in memory, and executed with `Assembly.Load(byte[])`. Nothing executable is ever written to disk. Sekoia's I2PRAT analysis shows the same principle applied to configuration — an AES-128-CBC blob with a per-sample key and IV, pushed via XMM instructions to stay out of the string table.

HEARTH had no coverage for **T1027.013 Encrypted/Encoded File**. This hunt targets the carrier file and, more importantly, the process that reads it.

## Why

- **It defeats the artifact everyone hunts for.** Signature scanning, MOTW checks, image-name allowlists and "unsigned PE in %TEMP%" rules all assume the payload exists on disk as code. Here it exists as pixel data. The hunt has to move to the read side — who opens this image, and why — because the write side looks like a cache file.
- **Structure lies less than extension does.** An extension is a naming convention; magic bytes, chunk ordering, and entropy are properties of the content. A `.db` that starts with the PNG signature, or a `.png` whose IDAT stream will not decode to an image, is a cheap and durable sweep that survives every rename the operator tries.
- **The reader is the anomaly, not the file.** Millions of legitimate PNGs and SQLite databases sit in `%AppData%`. Almost none of them are opened repeatedly by an unsigned binary that dropped them into its own scratch directory moments earlier. Pivoting on reader identity collapses the false-positive surface that extension-based hunting creates.
- **It is upstream of the expensive stages.** In Rapid7's chains these encrypted modules unpack into modular RAT plugins for keylogging, screen capture and browser-credential theft (see H247). Catching the carrier catches the whole plugin set in one place, before any of it runs.
